## 第⼀次 Git 实验总结
1. `git add` 的作⽤是：将工作区的文件改动添加到**暂存区**，标记这些改动准备提交，并不会真正生成版本记录。
2. `git commit` 的作⽤是：把暂存区里的改动保存到**本地 Git 仓库**，生成一条新的版本提交记录，保存快照，仅保存在本机。
3. 本次实验中 `git restore notes.md` 的作⽤是：丢弃工作区中 notes.md 还没有加入暂存的临时修改，把文件恢复到暂存区里的状态，撤销刚才追加的那行测试文字。
4. `commit` 与 `push` 的区别是：`commit` 在**本地电脑**生成版本快照，改动只存在本机；`push` 将本地已经完成的 commit 记录上传推送到远程仓库（Gitee/GitHub），把本地版本同步到网络服务器。
