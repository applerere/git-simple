我的 Git 学习笔记

1. `git add`：将工作区中的修改添加到暂存区，为后续`commit`提交做准备，此时改动还没有保存到版本库。
2. `git commit`：把暂存区内的变更保存到本地版本库，生成一条提交记录，仅保存在本地，不会自动上传到远程仓库。
3. 本次实验 `git restore notes.md`：撤销工作区中还未执行`add`的修改，将`notes.md`文件恢复到最近一次提交的状态，丢弃未暂存的新增内容。
4. `commit` 与 `push` 的区别：`commit` 是把变更保存到本机的 Git 本地仓库，生成版本快照；`push` 是将本地已经`commit`好的提交记录，推送到 GitHub 这类远程仓库，同步版本到远程服务器。
